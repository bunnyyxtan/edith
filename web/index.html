The problem

Agents can pay now. They still can't tell what's worth paying for.

  1. 01

    It pays for empty answers

    A paid API takes the money and returns an empty body or an error. Nothing in the agent notices.

  2. 02

    It repeats the mistake

    Every session starts with a blank slate, so tomorrow the same bad request gets paid for again.

  3. 03

    Payments are final

    A settled transfer on Sui cannot be reversed. The only moment to be careful is before paying.

The product

A judgment step in front of every payment.

Before a single SUI moves, Edith reads what it remembers about the request and the endpoint, checks the price, and decides.

    Security and control

    Careful with money, by design.

    Limits live in code, not in a prompt. An agent cannot talk its way past them.

    • Your keys stay yours

      Edith never holds a private key. Signing in proves the wallet is yours and grants no spending power. Every payment is a transfer your wallet signs.

    • Limits you set

      A most-per-payment and a most-per-day, checked before a price is shown and again before a signed payment is sent. Never above 0.01 SUI a call.

    • Checked before it leaves

      Each signed transfer is simulated first and sent only if it pays the exact quoted amount, to the quoted provider, from your account.

    • Every payment spent once

      Quotes expire in five minutes and providers keep a ledger of settled transactions, so one payment can never unlock two answers.

    • Outages don't cost twice

      If an answer goes missing, Edith checks Sui before anything else. A 5xx earns a cool-down, not a second payment.

    • Open source

      MIT licensed. Read every line that touches your money, then run it on your own keys.

    FAQ

    Questions, answered.

    What counts as a call that wasn't worth it?

    An empty or malformed response, or a 4xx error after payment. That exact request is never paid for again. A 5xx is treated as temporary: the request cools down for fifteen minutes before one retry.

    Does Edith hold my money or my keys?

    No. You connect your own Sui wallet, and it signs each payment you approve. Edith checks the signed transfer and hands it to the provider, but it never holds a key, a seed phrase or a balance.

    Can a payment be refunded?

    No. Payments settle on Sui and are final, and Edith never claims otherwise. That is why every decision happens before paying, not after.

    Which APIs can Edith pay?

    Any API that answers with an HTTP 402 and x402 payment terms in SUI, signed the way Edith's paywall signs them. The paywall ships in the same repository, so a provider can adopt it in an afternoon.

    Where does the memory live?

    In Walrus Memory, under a namespace owned by your account. It is read before each payment and written after each paid call, so it survives restarts and moves between machines.

    What does Edith cost?

    Edith is free and open source under the MIT license. You pay only the prices the APIs ask, plus Sui gas.
